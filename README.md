# Prag Music

A personal music app built with Expo, made to run on my phone through Expo Go.

The goal is a music player that beats Spotify for one listener: me. Every part of it, from how the library is organized to how recommendations work, gets shaped around how I actually listen.

## Status

Early setup. This repo holds the README and nothing else yet. The Expo app gets scaffolded next.

## Planned stack

- Expo (React Native) with Expo Go for development on device
- TypeScript
